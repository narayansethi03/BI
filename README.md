
# Pokemon PokeDax

The Pokédax for Generation 1 Pokémon, created in Power BI, integrates data from various sources, including Kaggle, Wikipedia, and GitHub. This project aims to provide comprehensive yet practical insights into Generation 1 Pokémon, helping you strategically build your dream team! 

The report acts dynamically with selected pokemon making the report more interactive yet insightful. 



## KPIs

In order to assemble the dream team, it is vital to see who is effective against whom. To address this problem, I have utilized DAX to analyze the strengths and weaknesses of each Pokémon.

Most Effective Against: This determines the type of Pokémon against which the selected Pokémon will perform best. This is calculated using DAX by totaling the damage taken while fighting Pokémon of other types.

Least Effective Against: This identifies the type against which the selected Pokémon will not perform effectively. This is calculated by summing all the damage taken against each type and identifying the type that inflicted the most damage.

Attributes: Spider charts are particularly effective in visually representing attributes, making them easier to understand and compare. This visual approach enhances comprehension and serves as a valuable tool for comparing different attributes.
